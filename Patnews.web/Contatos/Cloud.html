7. Passo a Passo: Hosting na Nuvem (Aiven)

  1. Cadastro: Criação de conta na plataforma Aiven.io.
  2. Provisionamento: Criação de um novo serviço selecionando o engine MySQL no plano gratuito (Free Tier).
  3. Obtenção de Credenciais: Cópia das informações de conexão: Host, Port, User, Password e certificado SSL.
  4. Conexão Remota: Configuração no client SQL (DBeaver / MySQL Workbench) utilizando conexão com SSL habilitado.
  5. Execução do Script: Execução do script DDL e DML para criação das estruturas e inserção de dados em nuvem.

8. Dump e Backup do Banco de Dados

Para garantir a segurança dos dados e permitir a rápida restauração do ambiente, foram documentadas as rotinas de dump via linha de comando:

Exportação Completa (Estrutura + Dados)

mysqldump -u root -p --databases assetcontrol_db > dump_assetcontrol.sql

Exportação Apenas da Estrutura (DDL)

mysqldump -u root -p --no-data assetcontrol_db > estrutura_assetcontrol.sql

Restauração do Backup

mysql -u root -p assetcontrol_db < dump_assetcontrol.sql
